# 5341: hunger

A state of emptiness, reflecting a lack of physical or spiritual food. Scripture recognises the physical aspects of human hunger which can only be met by the living God.



## Kinds of hunger


### Physical
**DEU 8:3**

### Spiritual
**MAT 5:6** *See also* PSA 63:1, PSA 63:5, PSA 107:9; AMO 8:11; LUK 6:21; JHN 6:35; 1PE 2:2

## Causes of hunger


### Famine
 GEN 41:55; ; 2KI 6:25-6:29; ; NEH 5:1-5:2

### Fasting
 MAT 4:2 parallel LUK 4:2

### Fatigue
 1SA 21:3; ; 2SA 17:29; ; MAT 12:1-12:4; ; MRK 6:35-6:36, MRK 8:2-8:3

### Folly
 PRO 19:15, PRO 20:4; ; LUK 15:14

### God's action
 LEV 26:26; ; DEU 28:48; ; ISA 5:13, ISA 9:20; ; EZK 7:19

### The hardships of gospel work
 1CO 4:11; ; 2CO 6:5, 2CO 11:27; ; PHP 4:12

## Effects of hunger


### Physical deterioration
 JOB 30:3; ; LAM 2:19, LAM 4:9

### Mental preoccupation
 ISA 29:8; ; ACT 10:10-10:13 *Peter's consciousness was supernaturally heightened to receive a vision from God.*

### Moral degradation
 LEV 26:29; ; DEU 28:53; ; 2KI 6:28-6:29; ; JER 19:9; ; LAM 2:20, LAM 4:10; ; EZK 5:10

### An occasion for temptation
 GEN 3:6 *Eve*; ; GEN 25:29-25:34 *Esau*; ; PRO 6:30-6:31; ; ISA 8:21; ; MAT 4:3 parallel LUK 4:3 *Jesus Christ*

### An opportunity for proving God
 DEU 8:3; ; NEH 9:15; ; PHP 4:12

## God satisfies hunger


### He provides food for all creation
**PSA 107:9, PSA 145:15-145:16** *See also* DEU 32:13-32:14; PSA 17:14, PSA 37:25, PSA 104:21, PSA 104:27-104:28, PSA 111:5, PSA 132:15, PSA 136:25, PSA 146:7, PSA 147:9; ISA 49:10

### He provides through supernatural means
**PSA 78:24-78:25** *See also* EXO 16:12-16:15; 1KI 17:4-17:16; NEH 9:15; MAT 14:19-14:21 parallels MRK 6:41-6:44, LUK 9:16-9:17, JHN 6:11-6:14 *the feeding of the 5,000*; MRK 8:7-8:8

### He provides through natural means
 GEN 3:17-3:19; ; JOS 5:12; ; PRO 16:26; ; ISA 58:7; ; MAT 25:35; ; 2TH 3:10

### He provides completely in heaven
 REV 7:16

 MAT 4:2 parallel LUK 4:2; ; MAT 21:18 parallel MRK 11:12; ; JHN 4:31
