# 5925: rashness

Acting without careful consideration of the possible consequences or risks.



## Examples of rashness
 GEN 34:25-34:31 *Jacob's sons*; EXO 2:11-2:12; ; ACT 7:24-7:25; ; NUM 20:8-20:12; ; PSA 106:32; 
JOS 8:14-8:17 *the king of Ai*; ; JDG 11:30-11:31 *Jephthah*; ; 1SA 14:24 *King Saul*; ; 2SA 6:6 *Uzzah*; ; 2SA 12:18 *fear for King David*; ; 1KI 1:5 *King Adonijah*; ; 2KI 5:20-5:21 *Gehazi*; ; 2KI 10:16 *Jehu*; ; 2CH 26:16-26:20 *King Uzziah*; ; 2CH 35:21-35:22 *King Josiah*; ; HAB 1:6 *the Babylonians*; ; MAT 8:19-8:20 *a would-be disciple*; ; MAT 14:6-14:10 parallel MRK 6:26 *King Herod*; MAT 26:33-26:34; ; JHN 18:10; 
ACT 19:36 *the Ephesian crowd*; ; GAL 1:6 *the Galatian Christians*; ; 2TI 3:2-3:4 *a characteristic of the last days*
