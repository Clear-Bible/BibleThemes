# 5975: violence

Unrestrained physical or verbal force designed to hurt others, or to gain mastery over them.



## The world is full of violence
 GEN 6:11-6:13; ; JOB 24:2-24:4; ; PSA 55:9, PSA 74:20; ; PRO 13:2; ; ISA 59:1-59:8; ; EZK 7:23; ; MIC 2:1-2:2

## God hates violence
 PSA 11:5, PSA 139:19; ; JER 22:3; ; EZK 45:9; ; MAL 2:16

## Jesus Christ was not violent
 ISA 42:1-42:3, ISA 53:9; ; 1PE 2:23

## Christians should not be violent
 GAL 5:19-5:21; ; EPH 4:2, EPH 4:31; ; PHP 4:5

## Christian leaders should not be violent
 1CH 22:8-22:9; ; 1TI 3:3; ; 2TI 2:24; ; TIT 1:7

## God helps the victims of violence
 2SA 22:3, 2SA 22:49; ; PSA 18:48, PSA 72:14, PSA 140:1-140:4; ; MAT 2:13; ; LUK 22:50-22:51

## Christians should help the victims of violence
 GEN 14:14; ; 2CH 28:9-28:15; ; JER 38:9-38:12; ; LUK 10:30, LUK 10:33; ; ACT 23:15-23:16
